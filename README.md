# Консольный калькулятор на Java

Простой консольный калькулятор, написанный на Java в рамках учебного задания.

Калькулятор позволяет выполнять основные арифметические операции и продолжать вычисления с уже полученным результатом.

## Возможности

- Сложение (+), вычитание (-), умножение (\*) и деление (/)
- Работа с целыми и дробными числами с использованием double
- Продолжение вычислений с результатом предыдущей операции
- Сброс текущего результата командой C или c
- Завершение программы командой S или s
- Проверка деления на ноль
- Сообщение об ошибке при вводе неподдерживаемой операции

## Ответы на вопросы задания

### Какой оператор лучше использовать для определения математической операции?

Лучше использовать switch, так как набор операций небольшой и заранее известен: +, -, \*, /.

### Нужно ли сообщать о неподдерживаемой операции?

Да. Если пользователь ввёл неподдерживаемую операцию, лучше сообщить ему об ошибке. При этом текущий результат не должен изменяться.

### Нужна ли дополнительная переменная для второго операнда? А для результата?

Да. Второй операнд нужно хранить в отдельной переменной, так как он вводится пользователем для каждой новой операции.

Для результата также нужна отдельная переменная. В ней можно хранить текущий результат вычислений, который затем будет использоваться как первый операнд для следующей операции.

### Можно ли написать весь код в одном методе? Или вынести код для каждой операции в отдельный метод?

Для такого небольшого калькулятора можно оставить основную логику в одном методе. Выносить каждую математическую операцию в отдельный метод здесь не обязательно, так как это только усложнит код. Сами операции удобно обработать через switch.

### Как обрабатывать команды управления калькулятором (например, сброс результата или завершение работы)?

Команды управления лучше обрабатывать отдельно от математических операций. C или c могут сбрасывать текущий результат, а S или s — завершать работу программы. Чтобы не учитывать регистр, можно использовать equalsIgnoreCase.
