# MIFI-JAVA

Учебные приложения на Java. Каждое приложение находится в отдельной ветке.

| Приложение               | Описание                                               | Ссылка                                                                                       |
| ------------------------ | ------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| Консольный калькулятор   | Арифметические операции с целыми и дробными числами.   | [practic/calculator](https://github.com/lenchitskiy-Yuliy/MIFI-JAVA/tree/practic/calculator) |
| Погода                   | Получение прогноза погоды по координатам.              | [practic/weather](https://github.com/lenchitskiy-Yuliy/MIFI-JAVA/tree/practic/weather)       |
| Личные финансы           | Учёт доходов и расходов, категории и бюджеты.          | [feat/finance](https://github.com/lenchitskiy-Yuliy/MIFI-JAVA/tree/feat/finance)             |
| Сервис сокращения ссылок | Короткие ссылки с лимитом переходов и сроком действия. | [feat/short-link](https://github.com/lenchitskiy-Yuliy/MIFI-JAVA/tree/feat/short-link)       |
